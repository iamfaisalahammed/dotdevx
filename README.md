# .DevX — Web Development Agency

A modern web development agency building high-quality digital experiences for businesses in Bangladesh and worldwide.

**Website:** https://dotdevx.com

## Services

- Website Development
- Business Websites
- Landing Pages
- E-commerce Development
- Full-Stack Web Applications
- Website Redesign

## Tech Stack

- Next.js 16 (App Router)
- JavaScript / JSX
- Tailwind CSS v4
- Framer Motion
- Lucide React
- Cloudflare Workers

## Features

- Modern, responsive design
- Mobile-first layout
- Smooth animations
- Services and portfolio showcase
- SEO optimization
- WhatsApp, email, and phone integration

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production Build

```bash
npm run build
```

## Deployment

Deployed using **Cloudflare Workers** with the OpenNext adapter.

Documentation: https://developers.cloudflare.com/workers/framework-guides/web-apps/nextjs/
